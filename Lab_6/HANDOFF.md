## 4. ЗАВДАННЯ 1 — РОЗУМНІ ВАЛІДАТОРИ (spec)

### 4.1 Нові хелпери в `src/lib/validate.ts` (додати)

```ts
/** Телефон UA: +380 + 9 цифр (12) або 0 + 9 цифр (10).
 *  Дозволені роздільники: пробіл ( ) - . ; необов'язковий «+» на початку. */
export function isUaPhone(v: string): boolean {
  if (!/^\+?[0-9][0-9()\-. \t]*$/.test(v)) return false;
  const d = v.replace(/\D/g, "");
  return (d.length === 12 && d.startsWith("380")) || (d.length === 10 && d.startsWith("0"));
}

/** true, якщо у числі ≤ max знаків після коми/крапки (для ціни/годин). */
export function maxDecimals(v: unknown, max = 2): boolean {
  const s = clean(v).replace(",", ".");
  const i = s.indexOf(".");
  if (i === -1) return true;
  return s.length - i - 1 <= max;
}

export const MIN_DATE = Date.UTC(1990, 0, 1); // дати раніше 1990 — недопустимі
```

Застосовувати `isUaPhone` замість `isPhone` (старий `isPhone` можна видалити або лишити).

## 5. ЗАВДАННЯ 2 — ПЕРЕПИСАТИ `scripts/lab3-e2e.sh` (зараз ПОШКОДЖЕНИЙ)

### 5.1 Чому e2e падав (корінь знайдено, докази є)

- Топ-рівневий shell середовища = **MINGW64/Git-Bash** (`MSYSTEM=MINGW64 OSTYPE=cygwin`),
  а його `curl` — **нативний Windows-бінарник** (`/mingw64/bin/curl` або `system32\curl.exe`).
- Git-Bash **конвертує argv нативних бінарників UTF-8 → cp1251 (ANSI)** → українські символи
  у `curl -d "..."` прилітають на сервер пошкодженими → зберігаються як `U+FFFD`/`?`.
- Докази: node fetch (чистий HTTP, тіло raw UTF-8) → зберігається **ідеально**;
  `sh script.sh` з `curl -d "UA"` → **м'ябок**; argv-строка з cp1251-безпечними літерами → чисто.
- WSL-шлях **мертвий**: WSL не має мережі до Windows-хоста (gateway :3000 → 000).
- **Вирішення:** в e2e **усі** дані `curl -d` писати **percent-encoded ASCII**
  (не-ASCII байти → `%XX`, пробіл → `%20`; `&`, `=`, `+` лишати). body-parser декодує `%XX`
  як UTF-8 — тотожно браузеру. Гріпи/awk/echo-патерни **залишати UTF-8** (`/usr/bin` у Git-Bash
  — MSYS2 POSIX-інструменти, argv там НЕ конвертується).
- **НЕ** покладатись на `/usr/bin/curl` — у Git-Bash його немає (тільки `/mingw64`),
  а середовище cells **варіюється** (іноді WSL) — percent-encoding працює скрізь.

### 5.2 Що конкретно зламано в поточному файлі (210 рядків)

### 5.3 Структура нового скрипту (ціль: **129** перевірок at runtime = 117 базових + 12 нових)

> **Якір для лічби:** у поточному (пошкодженому) файлі **113 статичних** `ck "..."` викликів;
> в циклі GLOBAL один статичний `ck` виконується 5 разів → **117 at runtime** (113 + 4).
> При переписуванні **зберігти всі імена `ck` з поточного файлу** (вони всі читабельні) + додати 12 нових.
> Якщо після перепису лічба інша — ціль: `fail=0` і `pass` = фактична кількість, але 12 нових — обов'язково.

Шапка:
```sh
#!/bin/bash
# Lab 3 E2E — форми + серверна валідація + видалення. Запуск: sh scripts/lab3-e2e.sh
# ВАЖЛИВО: дані curl -d — percent-encoded ASCII (Git-Bash ламає UTF-8 в argv нативного curl).
B=http://localhost:3000
P=0; F=0
ck() { if [ "$2" = "$3" ]; then P=$((P+1)); else F=$((F+1)); echo "FAIL: $1 (expect [$2], got [$3])"; fi; }
code() { curl -s -o /dev/null -w "%{http_code}" "$@"; }
body() { curl -s "$@"; }
postloc() { # -> "CODE LOCATION"
  curl -s -D - -o /dev/null -X POST "$1" -d "$2" | tr -d '\r' | awk '
    /^HTTP\// { c = $2 }
    tolower($1) == "location:" { l = $2 }
    END { print c, l }'
}
```

## 8. ПАВУКИ СЕРЕДОВИЩА (обов'язково до прочитання)

- **Shell-ролетка:** середовище топра рівня варіюється від виклику до виклику —
  зазвичай MINGW64/Git-Bash, іноді WSL. `bash <скрипт>` → WSL (мережа до Windows :3000 **немає**, все 000);
  `sh <скрипт>` → Git-Bash (curl працює). Тому e2e — **`sh`**.
- **UTF-8 в argv = смерть:** у `curl -d "UA"` та `node -e 'UA...'` з Git-Bash UA-символи ламаються
  (cp1251). Тести/перевірки байтів — через файли або `docker exec ... psql` + node-скрипт (файл, не `-e`).
- PowerShell через bash-інструмент з'їдає `$_`/`$m` (одинарні лапки навколо `-Command`).
- psql: `docker exec lab1_service_db psql -U postgres -d lab1_service`; таблиці в `"лапках"`.
- Гrep-інструмент середовища не рахує `-o` — рахунок: `tr | sed | awk` або node.
- `npx prisma migrate reset` без змовного env-варіабля **відхилиться** (захист від випадкового reset) —
  ставити змінну з §5.4 (згода замовника є).
- Проміжні рядки `U+FFFD` у `"WorkCatalog"` від попередніх тестів — при reset зникнуть самі.
