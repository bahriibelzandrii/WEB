# Вебтехнології (WEB)

Комплекс лабораторних робіт з курсу **«Вебтехнології»**.  
Проєкт: **«Сервіс ремонту та обслуговування комп'ютерної техніки»** — веб-застосунок повного циклу на базі Node.js, Express, TypeScript, Prisma ORM, PostgreSQL та Pug.

* **Виконав:** Багрій-Белз Андрій  
* **Група:** КН-2327Б  

---

## 🛠️ Загальний стек технологій

- **Runtime:** Node.js 24 LTS
- **Мова програмування:** TypeScript 7 (`tsx` 4)
- **Backend-фреймворк:** Express 5.2.1
- **Шаблонізатор (SSR):** Pug 3.0.4
- **ORM / База даних:** Prisma ORM 7.10.0, PostgreSQL 18
- **Контейнеризація:** Docker, Docker Compose
- **Стилізація:** Сучасний чистий UI з семантичною версткою

## 🚀 Запуск та перевірка

Кожна лабораторна робота є самодостатньою та містить скрипти автоматизованого запуску:

1. Перейдіть до директорії потрібної лабораторної роботи:
   ```bash
   cd Lab_1   # або Lab_2 / Lab_3
   ```
2. Скопіюйте `.env.example` у `.env` (за потреби скоригуйте параметри підключення до БД):
   ```bash
   cp .env.example .env
   ```
3. Запустіть застосунок через один-клік скрипт:
   ```cmd
   start.bat
   ```
4. Для зупинки сервісів:
   ```cmd
   stop.bat
   ```

Детальні інструкції та тест-плани наведені у `README.md` всередині кожної лабораторної роботи.
